To Create a new branch (and stay on your current branch)
							git branch NewTestBranch

Create a new branch and switch to it immediately
							git checkout -b NewTestBranch
							
----------------------------------------------------------------------------------------------------------------------------------------

							git checkout NewTestBranch

							git branch																<-|
